### **Methodology**

#### **Data Source**

Sentinel-2 Surface Reflectance imagery obtained from Google Earth Engine.



#### **Data Processing**

1. Define study area.
2. Filter Sentinel-2 imagery by date and cloud cover.
3. Generate median composite image.
4. Calculate NDVI using: **NDVI = (NIR - RED) / (NIR + RED)**
5. Export NDVI raster.
6. Analyze raster using Python.
7. Generate statistics.
8. Produce vegetation condition map.



#### **Software Used**

* Google Earth Engine

#### **Outputs**

* NDVI raster
* NDVI statistics
* Vegetation condition map
